# Painel PRO • Plugin para SSMedia

Plugin de gerenciamento completo no padrão Xtream Control para o ecossistema SSMedia.

## 🚀 Instalação no SSMedia via URL

Na tela de Plugins do seu painel SSMedia:
1. Clique em **Instalar / Atualizar Plugin**.
2. Selecione a opção **Por URL**.
3. Cole o link público direto:
```text
https://raw.githubusercontent.com/gleysomfernandesir112-sys/painel-pro-plugin/main/painel-pro-plugin.json
```
